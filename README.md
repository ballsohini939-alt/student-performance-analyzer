# Student Performance Analyzer 📊

Student Performance Analyzer is a Python project designed to help students keep track of their academic performance and study habits in one place.
The project is being built step by step as I learn Python and explore different ways to work with data.

## 🚀 What It Can Do

* Store student and academic information
* Record marks for different subjects
* Calculate overall percentage
* Check performance in individual subjects
* Keep track of study hours
* Find subjects where performance is stronger or needs improvement
* Provide simple performance statistics
